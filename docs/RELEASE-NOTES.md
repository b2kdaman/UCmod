UCmod 0.1.0-beta.1

First public beta for the tested Umbrella Corps Unity 5.2.3p1 x86 build.

- Ultrawide rendering, default 3440x1440.
- Configurable horizontal FOV, default 120 degrees, preserving weapon zoom.
- Height-fitted UI and aligned menu input.
- Toggle ADS on the configured aim input, enabled by default.
- Verified installer, original-runtime backup and restore script.

Close the game before installation. Extract the mod ZIP and follow README.txt.
The source archive is not the installable mod package.

Known limitations: some transition/death overlays remain centered at 16:9.
Not all ADS reset paths, weapons, missions, other resolutions or multiplayer
scenarios have been manually tested. This is an unofficial mod requiring a
separately installed copy of Umbrella Corps.
